# NetSwitch — 内网 IP / 网关 / DNS 多套配置一键切换

一个零依赖的 Windows 小工具：把常用的几套网络参数（IP、子网掩码、网关、DNS）存成「配置集」，需要切换时点一下就好，不用再去「网络和 Internet 设置」里一层层点。

纯 PowerShell + WinForms 实现，**不需要安装 Python / Node / 任何第三方库**，Windows 8 / Server 2012 及以上（含 Win10 / Win11）直接可用。

---

## 一、文件说明

| 文件 | 作用 |
| --- | --- |
| `NetSwitch.ps1` | 主程序（图形界面 + 命令行双模式），**核心文件** |
| `NetSwitch.bat` | 双击启动器，同目录下双击即可打开界面 |
| `profiles.json` | 你的配置集数据，**首次运行后自动在同目录生成** |
| `profiles.example.json` | 示例配置，可通过「导入配置」直接体验字段写法 |
| `README.md` | 本文档 |

## 二、快速开始

### 方法 1：图形界面（推荐）

1. 把整个文件夹拷到本地任意位置，例如 `D:\Tools\NetSwitch\`
2. 双击 **`NetSwitch.bat`**
3. 点左下角 **「新建」**，填一个名称（如「研发内网」）
4. 在下拉框里选中本机网卡，点 **「+ 添加网卡行」**，程序会自动把该网卡当前的 IP / 掩码 / 网关带出来，直接改成目标值即可
5. 点 **「保存」** → 选中该配置集 → 点 **「应用此配置集」**

> **修改 IP 需要管理员权限。** 首次点「应用」时会弹 UAC 授权；也可以直接右键 `NetSwitch.bat` → **以管理员身份运行**，界面右上角会显示绿色的「已获得管理员权限」。

### 方法 2：桌面快捷方式（最省事）

在界面里选中某个配置集，点 **「生成桌面快捷方式」**，桌面上会多一个 `NetSwitch-<配置集名>.lnk`。

以后**双击这个图标就等于切换**（快捷方式已预先标记「以管理员身份运行」，不会重复弹 UAC 之外的麻烦步骤）。这是给最常用的两三套环境准备的。

### 方法 3：命令行 / 脚本调用

```powershell
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -ListProfiles    # 列出所有配置集
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -ListAdapters    # 列出本机网卡名
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -ShowStatus      # 查看当前 IP/网关/DNS
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -Apply "研发内网" # 直接切换
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -Apply "研发内网" -Silent  # 切换后不暂停
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -ExportFile backup.json
powershell -ExecutionPolicy Bypass -File NetSwitch.ps1 -ImportFile team.json
```

`-Apply` 时如果发现不是管理员，会**自动弹 UAC 提权**并继续完成切换，无需手动右键。

## 四、字段填写说明

一条网卡记录包含这些字段：

| 字段 | 说明 |
| --- | --- |
| 启用 | 不勾选则该网卡在切换时被跳过 |
| 网卡名称/匹配 | 填网卡名（如 `以太网`）；也支持模糊匹配（`以太网*`）或 `*` 表示全部网卡 |
| 获取方式 | `静态IP` 或 `DHCP自动` |
| IP 地址 | 静态模式下必填 |
| 子网掩码 | 支持 `255.255.255.0` 或前缀长度 `24`，留空默认 `/24` |
| 网关 | 多个用分号隔开，可指定跃点数：`192.168.1.1;10.0.0.1:20`（冒号后为跃点数，越小优先级越高） |
| DNS 服务器 | 多个用分号隔开；**留空表示自动获取** |
| 附加路由 | 可选，`目标网段>下一跳`，如 `172.16.0.0/12>10.10.20.254`，多条用分号隔开 |

> 组合用法：获取方式选 `DHCP自动` 但 DNS 里填了地址，则 IP 自动获取、DNS 固定为指定服务器 —— 这在公司内网里很常见。

## 五、分享给同事

方式很简单：把 `NetSwitch.ps1` 和你的 `profiles.json`（或导出的一份 json）一起发过去，对方双击 `NetSwitch.bat` 就能用。若不想发文件，也可以导出 json 让对方「导入配置」。

同事机器上的网卡名若不一样，在编辑器里改「网卡名称」即可；更省事的办法是把这一列填成模糊匹配，比如 `以太网*`。

## 六、常见问题

**1. 双击 bat 一闪而过 / 提示「禁止运行脚本」**

系统执行策略限制。解决方式任选其一：

- 用 `NetSwitch.bat` 启动（它内部已经带了 `-ExecutionPolicy Bypass`）
- 或在 PowerShell 里执行一次：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

**2. 提示需要管理员权限**

修改 IP、网关这类操作必须是管理员。右键 `NetSwitch.bat` → 以管理员身份运行即可；或在界面右上角点「提权并重启」。

**3. 中文显示乱码**

`NetSwitch.ps1` 已按 **UTF-8 BOM** 保存，Windows PowerShell 5.1 下不会乱码。如果自己用记事本改过并另存为 ANSI，可能会异常，建议用 VS Code 保存为「UTF-8 with BOM」。

**4. 切换后网络短暂断开**

正常现象。网卡 IP 变更时会断一下，通常 1~3 秒恢复。日志里没有红色报错即可。

**5. 想保留当前网络配置怎么办**

先在界面里「新建」一个配置集，添加网卡行时程序会自动把当前 IP / 掩码 / 网关带出来，改名保存即可 —— 相当于把当前状态存档了。

**6. 会不会把 `profiles.json` 写到奇怪的地方**

不会。默认读写脚本同目录的 `profiles.json`；只有在同目录不可写时才回退到 `%APPDATA%\NetSwitch\profiles.json`。也可以用 `-ConfigPath 路径` 显式指定。

## 七、日志与出错求助

工具会自动写日志，不用额外配置：

| 项目 | 说明 |
| --- | --- |
| 日志位置 | 脚本同目录的 **`NetSwitch.log`** |
| 记录内容 | 启动时的环境快照（系统 / PowerShell 版本 / 是否管理员 / 配置文件路径）、每次切换做了什么、每一步是否失败、失败的具体原因 |
| 界面查看 | 主界面右下角「操作日志」面板实时显示，**窗口关闭也不会丢** |
| 自动清理 | 超过 1MB 时只保留最近 500 行，不会无限增长 |
| 快速导出 | 点右下角 **「复制日志」**，自动把最近 300 行复制到剪贴板 |

**出错时怎么反馈**（推荐顺序）：

1. 在界面点 **「复制日志」**，把内容直接粘贴过来 —— 里面已经有环境信息和出错行
2. 若界面打不开，直接去脚本目录找 **`NetSwitch.log`**，把最后几十行发来
3. 命令行模式同样会写日志：`NetSwitch.ps1 -Apply "配置集名"` 之后查看日志文件

日志里会包含你的内网 IP 和 Windows 用户名，贴给别人之前留意一下是否需要脱敏。

## 八、安全提示

程序执行的所有底层命令都是 Windows 自带的 `NetTCPIP` 模块 cmdlet（`Get-NetAdapter`、`New-NetIPAddress`、`Set-NetIPInterface`、`Set-DnsClientServerAddress`、`New-NetRoute` 等），不涉及第三方驱动或注册表修改。切换前会清除网卡上已有的 IPv4 地址与默认网关，因此**建议先把当前环境存成一个配置集再开始用**。
